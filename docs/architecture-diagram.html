控制面职责
  • 统一 REST / CLI 入口
  • 鉴权、多租户、限流
  • 入队任务、中继控制、SSE 回流
  • 屏蔽底层 orchestrator / 沙箱细节
Harness 职责
  • 驱动 Agent 运行循环（在沙箱内）
  • 调用工具 / MCP / 技能完成任务
  • 管理上下文、允许中断与续跑
  • 把事件经 gRPC AgentBridge 流回
状态层职责
  • 持久化会话全量状态与历史
  • 支持续跑与版本回溯
  • 提供检索、用量与成本核算
  • 保障数据按租户合规与隔离
